01 / VISION

把界面做成一封深海来信

页面用深海蓝、霓虹青和紫罗兰构成主色，配合鲸鱼娘剪影、气泡、月亮和轨道光环。 艺术字不是普通标题，而是整个视觉叙事的一部分：它像从水面下方升起的光。

02 / VISUAL LANGUAGE

三个核心视觉元素

所有元素都写在同一个 HTML 文件里：有品牌 logo、有艺术字、有鲸鱼娘主题插画， 也有类似桌面端启动器的片头动画。

A / LOGO

深海鲸鱼徽记

用简化的鲸鱼轮廓制作品牌标记，出现在导航栏、开机动画和页面视觉中心。

B / TYPE

流光艺术字

“未至之境”使用渐变填充、描边文字和英文副标题，形成桌面端皮肤海报式标题。

C / ART

鲸鱼娘主题图像

内嵌 SVG 插画展示月亮、深海鲸背和鲸鱼娘剪影，不依赖外链图片，上传后更稳定。
